# Captionator

Downloads for Captionator, a Mac app that turns videos into .srt subtitles.

- **Apps:** see [Releases](../../releases). Download the zip, unzip, drag Captionator to Applications and open it with right-click › Open the first time.
- **Speech model:** the app downloads its speech model once from the `model-turbo-q4` release here, then works fully offline.
  It is OpenAI's Whisper large-v3-turbo (MIT licence), 4-bit MLX version by mlx-community.
