# Pulse Captions

Downloads for Pulse Captions, a Mac app that turns videos into .srt subtitles, guided by a script, fully on the Mac.

- **Download:** see [Releases](../../releases). Take the `.dmg`, drag Pulse Captions to Applications and open it with right-click › Open the first time.
- **Updates:** the app checks here by itself and installs a new version with one click.
- **Speech models:** the app downloads its speech model once from the `model-turbo-q4` (Large) or `model-small-q4` (Small) release here, then works fully offline. Large is OpenAI's Whisper large-v3-turbo, Small is Whisper small (both MIT licence), as 4-bit MLX versions by mlx-community. These releases must never be removed: installed apps download from them.
- **Needs:** macOS 14 or later on a Mac with Apple silicon.

Pulse Captions was called Captionator before version 0.1.1.
